## 1. 已确认技术决策（固化，勿随意改动）

| 项目 | 决策 | 说明 |
|---|---|---|
| 框架 | Vue3 + Vite + TypeScript | 实习项目主流，构建快 |
| 状态管理 | Pinia | Vue3 官方推荐，逻辑层核心 |
| UI 组件库 | Element Plus | 表格/表单/弹窗/折叠面板齐全 |
| 地图引擎(主) | OpenLayers | 2D，数据好找（shp/geojson/wms/excel） |
| 地图引擎(辅) | Cesium | 最后阶段，仅视觉演示，无城市模型/地形 |
| 底图 | 天地图（WMTS，需 tk） | 国内合规，矢量/影像/注记齐全 |
| 后端 | Node.js + Express（轻量） | 代理 tk、解析 shp/excel、WMS 中转 |
| 数据格式 | Shapefile / GeoJSON / WMS / Excel | 全支持 |
| 空间分析 | 量算+逆地理+属性查询+缓冲区+叠加统计+勾画 | 用户要求"都要有" |
| 飞书 | 开发工作日志（字段见技能手册） | 每次修改/调试/尝试/问题/创新都记 |
| 协作 | Git + GitHub（分支/PR/合并） | 团队开发流程 |

### 后端用途说明（用户曾不确定，特此记录）
1. 代理天地图 tk：前端直连会暴露密钥，后端中转保护。
2. Shapefile 解析：浏览器读不了 .shp/.dbf/.prj 多文件，后端转 GeoJSON。
3. Excel 解析：后端用库读 xlsx 转 GeoJSON（带经纬度的行）。
4. WMS 代理（可选）：跨域中转。
5. 开发日志中转（可选）：前端一键推飞书，建议先用 SDK/手动。

## 2. 功能清单（完整，定稿）

### A. 项目脚手架与分层
- [x] `npm create vite@latest` 建 Vue3+TS 项目
- [x] 安装依赖：ol / pinia / element-plus / axios / xlsx / echarts / element-china-area-data（前端）；express + shapefile + node:sqlite 等（后端）
- [x] 目录分层（严格隔离三端）：
  ```
  src/
    data/        # 数据层：api 请求、数据源适配、仓储
    services/    # 逻辑层：地图业务、空间分析、Pinia stores
    views/       # 显示层：页面（多页面路由）
    components/  # 显示层：地图容器、控制面板、图表等
    router/      # 顶部导航路由与游客免登录守卫
    config/      # 天地图/后端地址配置
    styles/      # 齐风鲁韵国风设计系统 Tokens (theme.css)
  server/        # Node.js + SQLite 后端服务
  docs/          # 实习计划书/记录/分工/数据库与设计系统文档
  ```
- [x] 地图引擎抽象接口（OLMapAdapter），显示层只依赖接口
