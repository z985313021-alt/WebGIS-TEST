把山东的非遗项目搬到地图上，游客可以按门类筛选、看热度排名、点地图了解某个市， 还能在线买文创、追踪物流。管理员能收订单通知、发货、管理商品。

页面功能

🗺️ 地图主页

  • 左侧十门类印章墙，点哪个筛哪个
  • 常态展示非遗热度榜 Top 20
  • 点地图上的市 → 放大看该市非遗
  • 右下角实时温度（默认全省）
  • 右上角按需展开统计图表

🔬 分析工作台

  • 按批次（第 1-5 批）看非遗公布脉络
  • 地图可缩放、拖动、点选
  • 鹰眼图 + 比例尺 + 坐标显示
  • 门类构成环形图 + 地市排名柱状图
  • 支持缓冲区分析、地址搜索

🛒 文创商城

  • 非遗文创商品展示 + 热度榜
  • 购物车 + 抢购模式（60 秒内付款）
  • 订单列表 + 物流追踪
  • 管理员发货后用户实时收到通知
  • 商品详情关联对应非遗项目

💬 消息 + 通知

  • 右下角聊天按钮，未读数角标
  • 用户联系客服自动发送商品信息
  • 用户下单 → 管理员实时收到通知
  • 管理员发货 → 用户实时收到通知
  • 聊天列表：未读联系人置顶显示

技术怎么搭的？

🎨 前端（网页）

Vue 3 TypeScript Vite OpenLayers ECharts Element Plus

Vue 3 做页面框架，OpenLayers 渲染地图，ECharts 画图表，Element Plus 提供按钮/弹窗等组件，Vite 打包构建。

⚙️ 后端（服务器）

Node.js Express WebSocket SQLite Redis

Express 处理网页请求，WebSocket 负责实时推送，SQLite 存业务数据，Redis 缓存验证码和会话。

部署在哪？

🖥️ 服务器

  • 阿里云 ECS（2 核 2 内存）
  • Alibaba Cloud Linux 3（CentOS 系）
  • nginx 做网页服务器 + 接口代理
  • Node 22 + systemd 守护进程

🌐 访问方式

  • 公网 IP 直接访问（端口 80）
  • 天地图瓦片 + 高德地图代理
  • 备用端口 8081 / 18080（防运营商劫持）
  • 安全组只放行 80 / 443

📁 代码管理

Git 版本控制，dev 分支开发 → PR 合并到 main。钩子保护 main 分支，推送前自动跑测试。
