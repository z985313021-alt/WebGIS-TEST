平台采用 WebGIS + 时空知识图谱 技术，将山东省国家级与省级非物质文化遗产项目映射到地理空间， 实现非遗名录的可视化检索、空间分布分析、热度态势感知与文旅融合应用。 游客可在线探索非遗地图、参与抢购文创、追踪物流状态；管理员可管理商品、发货、查看实时订单通知。

WebSocket 实时通信

连接流程

// 1. 握手
ws://host/ws?token=xxx
// 2. 服务器校验
getUserByToken → 注册连接
// 3. 事件推送
notifyAdmins / notifyUser
// 4. 客户端分发
window.dispatchEvent('ws-event')

事件类型

  • order:created/paid/cancelled/done → 通知管理员
  • order:shipped → 通知订单用户
  • message:private → 私聊消息实时推送
  • connected → 握手成功确认
心跳 60s 断线重连 5s 一次性校验

私聊消息角标

收件人实时收到消息 → 聊天按钮角标 +1 → 联系人列表顶部"未读消息"分区 → 点击进入聊天后标记已读 → 角标清零。 全程无需刷新页面，WebSocket + Vue 响应式驱动 UI 自动更新。
