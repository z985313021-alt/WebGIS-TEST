## 0. 项目定位（一句话）

**山东省非物质文化遗产 WebGIS 可视化系统**：把山东省各级非遗项目（名录 + 传承人）以空间点位形式展示在真实地图上，支持按地市/类别/批次筛选、空间分析、图表统计与游览路线规划。

- 技术栈：Vue3 + Vite + TS + Pinia + Element Plus + **OpenLayers**（真实瓦片地图）+ ECharts + Node/Express 后端 + 天地图底图
- 与旧项目的关系：**继承数据与功能设计，重写技术实现**（旧项目是 C# WinForms + ArcEngine + WebView2 套皮，新项目纯 Web + 开源 GIS 引擎）

### 2.3 经验教训（旧项目 Bug 日志 → 新系统开发红线）

| 旧坑 | 教训 | 新系统对策 |
|---|---|---|
| Shapefile 字段名截断（10 字符） | 字段名不可信 | 转 GeoJSON 时统一重命名字段（如 `name/city/category/batch`） |
| 空值 `.ToString()` 崩溃 | 防御性编程 | 所有属性读取加空值兜底 `?? ''` |
| 批次字段 80% 为空/格式乱（'1' vs '第一批'） | 数据质量差 | 先跑数据体检；批次统计若不可靠就改用类别/地市统计 |
| CSV Excel 乱码（GB2312 vs UTF-8） | 编码坑 | Web 端导出统一用 XLSX 或 UTF-8 BOM |
| 坐标系缺失/不匹配（HRESULT 0x80040358） | 坐标系合规 | 数据导入时校验并统一转 WGS84（EPSG:4326） |
| 启动时序竞态（数据没加载完就体检） | 时序管理 | 前端 `loading` 状态 + 按需加载 |
| 路径硬编码导致"我这能跑你那不能" | 可移植性 | 一切路径走后端配置/相对路径 |
