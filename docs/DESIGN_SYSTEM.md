# 「齐风鲁韵」WebGIS 视觉系统设计规范 (Design System Tokens)

本项目为「齐风鲁韵」山东非物质文化遗产空间数字化平台，本规范用于约束平台内所有的 UI 界面重构、组件封装与动画动效，彻底杜绝无节制的“AI 套路味”（如无锚点悬浮胶囊、全屏 `border-radius: 999px`、发光气泡卡片等），树立端庄、克制、具备国家数字博物馆与专业 GIS 工业级水准的视觉体系。

---

## 1. 核心设计原则

1. **去“AI 味”，敬畏工程秩序**：
   - 严禁在正式 GIS 卡片、按钮、顶部栏或表格中滥用 `border-radius: 999px` 的“药丸/胶囊”形状。
   - 统一采用 **4px / 2px 结构化微圆角**：停靠轨与抽屉为 `0px`（平整贴边），卡片与容器为 `4px`，标签、徽章与印章为 `2px`。
2. **齐鲁风骨，宣纸墨韵**：
   - 界面底色以温润典雅的生宣、熟宣与白玉纸质感为基底；
   - 标题字系统一采用宋体/中宋（`"STSong", "Songti SC", "SimSun", serif`），正文字系采用现代无衬线体；
   - 点缀色取自传统国画与文保色彩：朱砂红、古铜金、松柏绿、墨玉黑。
3. **沉浸式地图视口保护**：
   - 侧边抽屉与操作栏采用“固钉+停靠（Docked）”设计，展开抽屉贴紧屏幕边缘，将居中开阔的地理主视口完整保留给用户。
4. **Canvas 与 OpenLayers 地图绝对稳定性底线**：
   - 绝对禁止在包覆 OpenLayers 地图视口、ECharts 画布的外层容器或路由过渡中使用 `transform: scale(...)` 或 `translateY(...)` 形变动画。
   - 过渡统一使用轻量平滑的纯透明度交叉淡入（`transition: opacity 200ms ease-out`）。

## 3. 布局结构规范 (Layout Architecture)

### 3.1 固钉主导航顶栏（50px Anchored Topbar）
- **尺寸**：高度固定为 `50px`，`flex: none`，置于页面顶部。
- **材质**：宣纸牙白 `#fffdf8`，底部 1px 金茶细线 `#e2d6be`，微阴影 `box-shadow: 0 1px 3px rgba(43, 34, 24, 0.05)`。
- **元素排版**：
  - 左侧：朱砂方印「齐鲁」（`padding: 2px 6px; border-radius: 2px; background: #8f2317`）+ 中宋主标题「遗蕴齐鲁」+ 浅墨副标题「山东省非物质文化遗产空间数字化平台」；
  - 中间：扁平导航 Tab，无圆角底块，选中项为底部 2px 朱砂红细线；
  - 右侧：4px 矩形朱砂红登录按钮 / 3px 方形文字头像 + 个人下拉菜单。

### 3.2 左侧深色停靠轨（48px Docked Left Rail）
- **尺寸**：宽度固定为 `48px`，贴紧视口最左侧（`top: 0; bottom: 0; left: 0`）。
- **材质**：墨石暗色 `#1c1815`，右侧 1px 深色边框 `#2e261f`。
- **图标与交互**：
  - 48×48px 扁平无圆角方块按钮；
  - 选中态：左侧 3px 古铜金 `#d4a84e` 竖线指示条，文字金色提亮。

### 3.3 左侧滑出抽屉（380px Docked Left Drawer）
- **定位**：紧贴左侧停靠轨展开（`left: 48px; top: 0; bottom: 0`），宽度 `380px`。
- **材质**：白玉纸色 `#fffdf8`，右侧 1px 分割线 `#dcd1ba`，无圆角。
- **标头**：高度 44px，米褐色 `#f7f2e7`，配设古典标头符号 `❖`。

### 3.4 右侧统计图表抽屉（420px Docked Right Drawer）
- **定位**：紧贴视口最右侧展开（`right: 0; top: 0; bottom: 0`），宽度 `420px`。
- **材质**：白玉纸色 `#fffdf8`，左侧 1px 分割线 `#dcd1ba`，无圆角。
- **与左侧呼应**：支持与左侧抽屉同时打开或独立收起，开阔的中央空间留给齐鲁全域地图。

## 4. 排版与图标红线

1. **严禁粗糙口语化 Emoji**：
   - 正式 WebGIS 界面标题、表格列头、图表及卡片中，严禁出现 🚄、💴、🛤️、📥、🌐、📋 等口语化 emoji。
   - 统一采用古典文印符号 `❖` 或 Element Plus 规范矢量图标（如 `<el-icon><Van /></el-icon>`）。
2. **标头字号层级**：
   - 页面大标题：20px ~ 24px，华文中宋，加粗；
   - 面板/卡片标头：14px ~ 16px，华文中宋；
   - 正文文本：12px ~ 13px，系统无衬线体；
   - 辅助标注/时间戳：10px ~ 11px。
